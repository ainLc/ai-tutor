# 系统架构设计 —— AI 私教学习系统

## 1. 整体架构

采用前后端分离 + 服务层解耦。核心思想：**把「会变化的能力」用适配层隔离，把「稳定的流程」用服务层固化**。  
公网收费能力（答辩、配额、熔断、指纹）按 `09_商业化架构增量.md` 增量加在同一进程内，不另起微服务。

```
┌─────────────────────────────────────────────────┐
│  浏览器 (Vue 3 + PWA)                            │
│  今日 · 听课 · 记忆练习 · 掌握 · 合上书答辩 · 设置 │
└──────────────────────┬──────────────────────────┘
                       │ HTTP / SSE
┌──────────────────────▼──────────────────────────┐
│                  FastAPI 后端                    │
│  api/ → services/ → models/                      │
│  core/: LLM · OCR · FSRS · 套餐配额              │
└──────────────────────┬──────────────────────────┘
                       │
                 ┌─────▼─────┐
                 │  SQLite   │ 课 / 进度 / 卡 / 答辩 / 套餐
                 └───────────┘
```

## 2. 分层职责

| 层 | 目录 | 职责 | 不负责 |
|---|---|---|---|
| 路由层 | `api/` | 接收请求、校验、鉴权、配额、SSE | 业务语义 |
| 服务层 | `services/` | 拆课、教学编排、答辩会话 | 具体模型调用 |
| 模型层 | `models/` | 持久化与迁移 | 产品规则文案 |
| 适配层 | `core/` | LLM / OCR / FSRS / 套餐常量 | 业务编排 |

**关键设计**：服务层只依赖「统一的 LLM 接口」。换模型 = 用户设置或 `.env`，不改业务代码。

## 3. 核心服务

### 3.1 拆课服务（CourseService）
- 输入：上传资料全文（文本层优先，不足则 OCR）
- 输出：课程 → 章节 → 知识点，并写入原文摘录与资料指纹

### 3.2 教学引擎（TutorService）
```
讲解（流式，锚定摘录）
  → Mermaid 配图
  → 苏格拉底过关
  → 未掌握：补讲 + 平行再测
  → 过关：制卡（FSRS）
```

### 3.3 答辩服务（DefenseService）
- 合上书开放提取，题面不展示原文
- 每题必须带 `source_ref`
- 判分复用掌握门，不另起标准
- 通过后出具一页可打印凭证（不含原文）

### 3.4 配图服务
- 流程图 / 架构图 / 对比表 / 时序图，Mermaid 前端渲染

## 4. 数据模型

```
User
  plan, circuit_override_until
  └── Course（source_hash 资料指纹）
        ├── Chapter → Lesson → Progress（理解轴）
        ├── Cards + review_logs（记忆轴，属学习者）
        └── DefenseSession（合上书答辩）
```

完成定义对外只允许三种文案：**已理解 / 已学过尚未记住 / 已记住**。没有「已完成」。

## 5. 关键技术决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 流式输出 | SSE | 单向推送够用 |
| 配图 | Mermaid | LLM 出文本即可 |
| 存储 | SQLite | 单机与早期公网够用；迁 Postgres 时表结构已规范化 |
| 间隔重复 | `fsrs` 库 | 不自造调度 |
| 凭证 | 前端排版 + 浏览器打印 | 避免 PDF 引擎；交付物仍是一页纸 |
| 多模型 | 适配层 + 每账号设置 | 自带 Key，毛利与 Token 解耦 |

## 6. 扩展性预留

- LLM：任意 OpenAI 兼容接口
- 存储：SQLite → PostgreSQL（表已有用户隔离）
- C1：掌握保险、团队闸在同一库加表，不拆服务
- 客户端：PWA 优先；原生只做壳
