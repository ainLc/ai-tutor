# 商业化架构增量（C0）

> 角色：架构  
> 版本：v1.0｜日期：2026-09-11  
> 依据：`08_产品扩展与商业化.md`（卖什么）＋`06_可行性开发方案.md`（怎么改库）  
> 原则：**不另起服务、不换栈。** FastAPI + Vue 3 + SQLite 继续。商业能力全部是幂等加表加列。

---

## 1. 结论

公网收费所需的系统能力，不是「再接一个更聪明的模型」，而是在现有掌握门 + FSRS 之上加四层 **结果操作系统**：

| 层 | 职责 | C0 落地 |
|---|---|---|
| 指纹 | 资料不可抵赖 | `courses.source_hash`（SHA-256） |
| 负荷 | 保持率优先于新课 | 到期 > 40 硬锁新课 + 知情覆盖 12h |
| 答辩 | 隔夜提取证明 | `defense_sessions` + 合上书出题/判分 |
| 契约 | 配额与凭证 | `users.plan`；凭证 HTML 打印；删除账号级联 |

C1（保险 / 团队闸 / 冲刺包支付）只预留字段与套餐枚举，本阶段不接支付通道。

## 2. 目标架构（相对 `02` 的增量）

```
浏览器 Vue
  今日 / 听课 / 记忆练习 / 掌握 / 合上书答辩 / 凭证打印 / 设置 / 法务
           │ HTTP + SSE
FastAPI
  api/routes  ── 鉴权、配额、熔断、SSE
       │
  services/
    course_service   拆课（已有）
    tutor_service    讲解/过关/制卡（已有）
    defense_service  合上书出题与会话（新增）
       │
  core/
    llm / ocr / scheduler / providers（已有）
    plans.py         套餐配额（新增）
       │
  SQLite
    原有表 + users.plan + courses.source_hash
    + defense_sessions + 熔断覆盖时间
```

服务层仍然只依赖统一 LLM 接口。答辩题必须带 `source_ref`，判分复用 `tutor_service.judge_answer`，避免第二套判题标准。

## 3. 数据模型增量

全部走 `init_db()` + `_migrate()`，旧库自动升级。

### 3.1 `users` 加列

```
plan TEXT DEFAULT 'free'                 -- free | pro | sprint
circuit_override_until TEXT DEFAULT ''   -- ISO；知情后 12h 内允许学新课
```

### 3.2 `courses` 加列

```
source_hash TEXT DEFAULT ''              -- 上传原文 SHA-256；资料替换则凭证作废
```

### 3.3 新表 `defense_sessions`

```
id, course_id, user_id
questions JSON   -- [{lesson_id, question, source_ref}]
answers   JSON   -- [{index, answer, verdict, feedback}]
status           -- pending | in_progress | passed | failed
created_at, finished_at
FOREIGN KEY(course_id) → courses ON DELETE CASCADE
```

记忆进度永不写入答辩表。答辩通过 ≠ 课程「已完成」；前端仍只允许：已理解 / 尚未记住 / 已记住。

## 4. 套餐与配额（`core/plans.py`）

| plan | 课程上限 | 正式凭证页眉 | 答辩 |
|---|---|---|---|
| free | 1 | 否（体验水印） | 允许练习 |
| pro | 99 | 是 | 允许 |
| sprint | 1 | 是 | 允许（C1 冲刺包占位） |

上传与导入分享前检查配额，超限返回 403，文案指向设置页切换套餐。  
**本阶段无支付网关**：设置页提供「演示切换」，上线接支付后关掉该入口。

## 5. 关键流程

### 5.1 负荷熔断

`today_summary` 增加：

- `overloaded`：`due_count > 40`
- `locked_new`：过载且覆盖未生效
- `override_until`

听课页：未开始的知识点在 `locked_new` 时不能开讲；欠账补讲与复习不受锁。  
覆盖必须勾选：「我知道这会降低 14 日保持率」。

### 5.2 合上书答辩

1. 至少 3 个知识点已理解才可开场。  
2. 出 6 道开放提取题，不给选项、不展示原文；每题绑定 `lesson_id` + `source_ref`。  
3. 判分走掌握门同一套 `mastered / partial / not_mastered`。  
4. 通过标准：≥ 80% 为 `mastered`。  
5. 凭证页：课程名、资料指纹短码、过关知识点占比、14 日保持率（若有）、题面与作答摘要。**不含原文全文。**  
6. free 套餐打印带「体验 · 非正式」水印；pro/sprint 使用正式页眉。

### 5.3 删除账号

`DELETE /auth/me`：删课、删卡、删复习日志、删 Key、删答辩、删用户。JWT 立即失效。

## 6. API（新增）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/billing/me` | 套餐、配额、已用课程数 |
| POST | `/api/billing/plan` | 演示切换套餐 |
| POST | `/api/home/circuit-override` | 知情后解锁新课 12h |
| POST | `/api/courses/{id}/defense` | 开一场合上书答辩 |
| GET | `/api/courses/{id}/defense` | 最近一场 |
| POST | `/api/defense/{id}/answer` | 答一题 |
| GET | `/api/defense/{id}/certificate` | 凭证数据（前端排版打印） |
| DELETE | `/api/auth/me` | 删除账号 |

## 7. 明确不做（避免架构膨胀）

- 不引入 PostgreSQL / Redis / 对象存储（公网第一张团队支票之前）  
- 不接支付、发票、短信；凭证用浏览器打印，不引入 PDF 引擎  
- 不上岗闸表、保险赔付表：等 C1，届时同样幂等加表  
- 不把答辩做成公开排行或「学完徽章墙」
