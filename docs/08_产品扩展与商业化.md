# 合上资料仍会：产品扩展与商业化

> 角色：产品  
> 版本：v1.0｜日期：2026-09-11｜状态：公网收费前的产品扩展规格  
> 依据：`05_学会并记住_产品战略与PRD.md`（方向不改）  
> 本文回答三件事：**凭什么别人抄不像、凭什么用户肯付钱、公网上线后先卖什么。**

现行产品承诺不变：上传资料 → 对着原文讲懂 → 不懂不能过 → 按遗忘曲线把该记的送回来。  
本文不另起一条「AI 课平台」路线。赚钱方式是把「两周后还在的能力」做成**可验证、可交付、可对公的结果**，而不是多卖几段讲解。

---

## 0. 先说结论（给决策用）

1. **能赚钱的不是「会讲课」。** 讲课已经商品化（ChatGPT、通义、NotebookLM）。用户付钱是为了：**合上我这份资料，过两周还能讲出来、用得上，并且有一份对得起别人的证明。**
2. **所谓「全网没有」不要吹成黑科技。** 单点技术（FSRS、苏格拉底、RAG）都有人做。真正稀缺的是 **同一条产品里同时满足四条硬约束**，而且商业模式不靠「刷完课」：
   - 只教用户自己的资料  
   - 不懂不能把进度写成学完  
   - 忘了要再教，不是翻卡片背面  
   - 完成定义对外可核验（能讲 + 14 日还能提取）
3. **公网第一年的钱主要来自两类人：**  
   - 个人：1–6 周内必须用某套资料过关的人（考证、答辩、转岗、内训考核）  
   - 小团队：要把「内部材料」变成上岗闸，而不是完播率报表的培训负责人
4. **定价卖的是结果契约，不是 Token。** 用户可自带模型 Key（已有设置页）。我们收的是掌握操作系统、负荷控制、合上书答辩、凭证与团队闸门。
5. **90 天只做 3 个收费锚点：** 合上书答辩、掌握保险、上岗闸。其余一律排期，防止又做成功能集市。

## 1. 市场判断：谁在付钱，谁只是热闹

### 1.1 现有市场的收费逻辑（以及我们为什么不跟）

| 玩家 | 收的是什么 | 用户买到的错觉 | 我们不跟的原因 |
|---|---|---|---|
| ChatGPT / 通义 | 对话次数与聪明程度 | 「问过了 = 会了」 | 不锚定我的资料，不拦过关 |
| NotebookLM | 资料工作区 + 播客/测验生成 | 「材料齐了 = 学会了」 | 生成完仍靠自觉 |
| Anki / 墨墨 | 记忆习惯与词库 | 「卡片清完 = 这门课会了」 | 不会先把复杂知识讲懂 |
| 得到 / 极客时间 | 内容版权与完播 | 「听完了 = 学完了」 | 被动听，不考，不记 |
| 企业 LMS | 完播率、考试分数、合规存档 | 「培训做完了」 | 分数可刷，两周后不会用 |

空白不在「再做一个更会讲的 AI」，而在 **结果不可伪造**：对方可以把进度条做绿，但不能假装 14 天后还能从脑子里把你这份资料的关键对比提取出来。

### 1.2 愿付费场景（按客单价排序）

| 场景 | 谁买单 | 失败代价 | 可接受月费量级（国内 2026） |
|---|---|---|---|
| 职业资格 / 证书考前 2–6 周 | 考生本人 | 报名费 + 一年时间 | 49–99 元/月或单次冲刺包 |
| 研究生开题 / 论文相关文献 | 学生 | 答辩当场讲不出来 | 29–69 元/月 |
| 转岗啃内部/开源技术文档 | 在职个人 | 试用期做不出活 | 39–79 元/月 |
| 公司新员工必须掌握制度/SOP/产品手册 | 培训/业务负责人 | 出事、客诉、事故 | 99–199 元/人/月或按席 |
| 讲师把资料变成可交付课 | 独立培训者 | 交付物像「又一份摘要」 | 按课打包 199–499 元 |

非用户仍然明确：**K12 学校采购、只想听播客的人、只背单词的人。** 他们不是嫌贵，是产品承诺对不上。

### 1.3 为什么现在适合上公网

本地已经具备收费所依赖的最小闭环：拆课锚点、掌握门、FSRS、今日复习、双进度、考试日、章末测验、前测、原文举报、自带 Key。  
公网缺的不是再堆功能，而是 **把闭环包装成别人愿意转介绍、愿意对财务报销的交付物。**

## 2. 差异化：六条「别人抄不像」的硬亮点

下面每条都满足三个条件：用户能感知、竞品抄了会伤自己的主营、能直接或间接变成订单。

### 亮点 A｜诚实学完（Anti-Completion）

**用户感知：** 系统里没有「已完成」。只有「已理解 / 已学过尚未记住 / 已记住」。听完全部讲解，文案仍是尚未记住。

**为什么难抄：** 内容平台和 LMS 的销售话术就是完播率。他们把进度条做诚实，等于当季报表变难看。

**收费关系：** 这是品牌信任的根。所有付费套餐都印这句话：**我们宁可变现少，也不把「看过」卖成「会了」。**

### 亮点 B｜合上书答辩（Closed-Book Source Defense）★ 第一年主打

**用户感知：** 一门课理解过关后，系统生成一场 8–12 分钟的闭卷口试/笔试：不给选项、不给原文，只允许用自己的话讲。每道题必须能指回上传资料的某一锚点。通过后出具「合上资料仍会」报告。

**和现在过关题的差别：** 过关题是学的时候当场考（资料刚看过，再认很容易混进来）。答辩是 **隔夜或隔章之后的提取证明**，专门打「当时好像懂了」。

**为什么难抄：** NotebookLM 可以出题，但没有掌握门，出完题没有「不通过就不能叫学完」。Khanmigo 有掌握路径，但不吃你的 PDF。Anki 有提取，但不做结构化答辩，也没有原文锚点报告。

**交付物（能发给导师/主管）：** 一页 PDF：课程哈希（资料指纹）+ 过关知识点 + 14 日保持率（若有）+ 答辩题与用户答案摘要。不公开原文，避免泄密。

### 亮点 C｜掌握保险（Retention SLA）★ 订阅转化器

**用户感知：** 付费用户可对一门课投保：自「全部知识点已理解」之日起 14 天，核心卡成功提取率若低于用户设定的目标（默认 90%），系统自动：拉回短间隔、赠送一次合上书复试、该课会员有效期顺延 14 天。不退现金，退的是 **把记住这件事做完的时间**。

**为什么这是产品不是赔钱促销：** 保险倒逼我们把制卡质量、复习负担、补讲做真。刷课产品不敢卖这个。

**规则（必须写进用户协议）：** 依从率过低（到期卡实际复习 < 70%）视为未履行练习，不触发顺延。防止「买了保险却不打开」。

### 亮点 D｜负荷熔断（Load Circuit Breaker）

**用户感知：** 今日到期 > 40 张时，新课默认锁定，文案是「你有 40 张今天不练就会掉，再学新的等于给自己挖坑」。可强行继续，但要勾选「我知道这会降低 14 日保持率」。

**为什么难抄：** 增长团队靠 DAU 和新课。我们靠保持率。拒绝让用户开始下一章，是反增长、亲结果的设计，会成为口碑。

**已有雏形：** 首页负担提示。扩展为硬锁 + 书面知情。

### 亮点 E｜上岗闸（Team Onboarding Gate）★ 团队订单

**用户感知：** 培训负责人上传 SOP / 产品手册，生成课。学员不是「看完视频」，而是：理解过关 + 至少一轮 3 日以上成功提取 + 合上书答辩通过，才算「可上岗」。负责人看板只显示：谁过闸、谁欠账、谁保持率掉了——**没有排行榜。**

**为什么难抄：** 企业 LMS 卖的是学时存档。把「可上岗」定义成记忆保持，采购指标要重写，他们内部推不动。我们从第一天就按这个口径卖。

**分享模型沿用现有：** 课结构可复制，记忆进度永不复制。

### 亮点 F｜原文指纹与幻觉追责（Source Fingerprint）

**用户感知：** 每门课保存资料指纹（哈希）与摘录定位。讲解可举报「不在资料里」。付费报告里写明：本课讲解与卡片均绑定该指纹；资料被替换则凭证作废。

**为什么值钱：** 对公场景最怕「AI 瞎编内规」。信任是企业订单的入场券。现有举报能力要升级成审计日志，而不是一个按钮。

## 3. 产品扩展清单（只服务上述亮点）

优先级：C0 公网能收费就必须有；C1 能明显提高客单或续费；C2 以后再说。

### 3.1 C0｜包装现有闭环，让人愿意掏钱

| 编号 | 功能 | 用户价值 | 主要改动面 | 对应亮点 |
|---|---|---|---|---|
| C0-1 | 合上书答辩会话 | 隔夜提取证明，可导出一页报告 | 新页 + 出题/判分（必须带 `source_ref`） | B |
| C0-2 | 掌握凭证 PDF | 发给导师/主管，不含原文 | 报告生成、课程指纹 | B / F |
| C0-3 | 负荷熔断 | 到期过多则锁新课 | 今日/听课页硬锁 + 知情勾选 | D |
| C0-4 | 套餐与配额 | 免费 1 门课 / 付费不限课或按门 | 账号套餐、课程数、答辩次数 | 商业 |
| C0-5 | 公网最小合规 | 隐私政策、资料归属、删除账号、密钥只存本账号 | 协议页、删除级联、Key 不明文回传（已有掩码） | 上线 |

### 3.2 C1｜提高续费与客单

| 编号 | 功能 | 用户价值 | 对应亮点 |
|---|---|---|---|
| C1-1 | 掌握保险 | 14 日不达标则顺延 + 强制回炉 | C |
| C1-2 | 团队空间与上岗闸 | 负责人看到过闸/欠账/风险，无排行 | E |
| C1-3 | 考前冲刺包 | 指定考试日 + 答辩 + 7 日保险，一次买断 | B / C |
| C1-4 | 易混点对打 | 从**用户自己的资料**里抽出成对易混概念，强制对比提取 | 制卡质量 → 保险赔付率下降 |
| C1-5 | 保持率周报 | 每周一封：「你有 N 张会掉；3 个最弱点；若考在周五风险如下」 | 召回 / 依从 |

### 3.3 C2｜不做或很后做（防止稀释）

- 内容商城、直播、短视频课、学习圈子、排行榜  
- 通用 ChatGPT、Agent 插件市场  
- 扫描件高级排版还原、播客双人对话（NotebookLM 的场）  
- 原生 App（PWA 够用再议）  
- 学校班级、未成年人合规包  
- 把「AI 画皮」当卖点（皮能被一周抄走）

### 3.4 体验优化（不单独当卖点，但影响转化）

公网第一观感决定付费。下列是包装，不是新方向：

- 空状态改成「上传将用于过关的那份资料」，禁止再写「开始学习之旅」  
- 首次上传后 90 秒内必须看到：章节树 + 「不懂不能过」的演示关卡  
- 设置页模型配置保留（自带 Key = 降低我们成本、提高极客信任）  
- 免费用户也看双进度，故意让「尚未记住」刺眼——这是转化文案，不是 bug

## 4. 商业模式

### 4.1 原则

- **模型费用尽量与毛利解耦：** 鼓励自带 Key；托管 Key 只放在付费档并计量。  
- **不按 Token 零售给小白。** 小白听不懂百万 Token，听得懂「一门课保 14 日」。  
- **团队不卖座位闲置。** 按「在学人数 × 过闸课数」或年席，但看板价值必须是过闸而不是登录天数。

### 4.2 套餐（建议挂网价，可按投放调整）

| 套餐 | 价格 | 给什么 | 不给什么 |
|---|---|---|---|
| 体验 | 0 元 | 1 门课、掌握门、今日复习、双进度、自带 Key | 答辩报告带公章式页眉、保险、团队 |
| 个人 Pro | 49 元/月或 399 元/年 | 多门课、合上书答辩与 PDF、负荷熔断、考前模式、周报 | 团队闸 |
| 冲刺包 | 69 元 / 14 天 | 一门课的答辩 + 考试日铺量 + 一次保险 | 年费权益 |
| 团队闸 | 129 元/人/月起，5 人起 | 上岗闸看板、课模板分发、过闸导出、资料指纹 | 排行、学时证明（除非客户加钱定制且文案不叫学完） |

**推荐主路径：** 体验把一门课学到「已理解」→ 第 2 天复习产生「原来会忘」→ 弹冲刺包或 Pro（文案：把「已学过尚未记住」买成「已记住」）。不要在注册页就强行年费。

### 4.3 单位经济（量级，用于算账不是承诺）

假设个人 Pro 用户月均 LLM 成本（托管 Key）8–20 元，自带 Key 接近 0。  
毛利目标：自带 Key 用户 > 85%；托管用户 > 50%。低于此则强制自带 Key 或涨价，**不许用融资补贴「无限 GPT」。**

团队订单服务成本在负责人支持，不在模型。一个 20 人内训闸，年度价值应能覆盖一次成功避免的客诉/事故叙事——销售话术走风险，不走「AI 很聪明」。

## 5. 获客与发布（公网怎么吸引客户）

### 5.1 不是投流砸品牌词

「AI 私教」「AI 讲课」已被巨头买红。我们买的是结果词与场景词：

- 「PDF 学完还是不会」  
- 「内训完播率高但上岗不会」  
- 「Anki 做不了这本讲义」  
- 「NotebookLM 之后怎么记住」

内容策略（持续 90 天，每周 1 条）：拿**同一份公开资料**（如一份开源文档某一章）做对照实验短文：只摘要 vs 我们过关+14 日提取。展示的是保持率，不是界面皮肤。

### 5.2 转介绍机制（符合产品原则）

- 分享课结构（已有），附带「我的保持率 91%，这是报告封面」——分享的是证明，不是进度炫耀。  
- 禁止邀请榜、金币、连续登录火焰。  
- 允许：把掌握凭证发给同事，同事用分享码导入**同一份资料的课**，记忆从零开始。

### 5.3 上公网的信任清单（否则付费会退）

- 资料默认私有，团队空间显式邀请  
- 删除账号 = 删课、删卡、删 Key  
- 密钥掩码（已有），日志禁打 Key  
- 讲解幻觉可举报，且进入保险是否赔付的质量统计  
- 不把公开看板当首页（现有全员看板保持折叠/P2，避免刷课）

## 6. 指标：公网以后看什么

北星仍是 **课程 14 日保持率**。商业化后加三层，不许用 DAU 替代北星。

| 层 | 指标 | 健康 |
|---|---|---|
| 结果 | Retention@14d；答辩通过率 | 付费用户应高于免费用户（否则卖的是皮肤） |
| 行为 | 复习依从率；熔断触发后仍学新课的比例 | 后者过高说明熔断文案失败 |
| 收入 | 体验→Pro 7 日转化；Pro 次月留存；保险触发率 | 保险触发率持续 > 25% 说明课/卡质量差，先停投放修产品 |
| 信任 | 幻觉举报 / 千次讲解；账号删除率 | 举报升则停托管模型 |

## 7. 90 天公网路线（只做能卖的）

### 第 1–30 天｜能公开、能收款、承诺不翻车

- 上线体验/Pro 套餐与配额（C0-4）  
- 合上书答辩 + 一页 PDF（C0-1/2）  
- 负荷熔断（C0-3）  
- 隐私/条款/删除账号（C0-5）  
- 落地页一句话：**合上你的资料，两周后还要能讲。** 演示用双进度，不要用「智能 AI」。

出口：陌生用户能注册、上传、过关、付费解锁答辩报告。

### 第 31–60 天｜续费理由

- 掌握保险（C1-1）  
- 考前冲刺包（C1-3）  
- 保持率周报（C1-5）  

出口：出现「因为保险/周报而续费」的用户访谈，而不是「因为模型更聪明」。

### 第 61–90 天｜第一张团队支票

- 团队空间 + 上岗闸看板（C1-2）  
- 原文指纹进凭证（C0 已埋点则补展示）  
- 只做 3 个标杆客户：新员工手册、客服 SOP、技术 Onboarding 各一，写进案例（隐去机密）。

出口：至少 1 个付费团队，口径是过闸人数，不是 DAU。

## 8. 风险（产品侧）

| 风险 | 为何致命 | 对策 |
|---|---|---|
| 把「全网没有」写成功能幻想 | 研发去做语音分身、3D 教室，差异被皮肤稀释 | 本文六条亮点以外的想法默认拒绝 |
| 答辩题太弱 | 凭证贬值，企业客户嘲笑 | 强制原文锚点；抽检；太容易通过则加严而不是加广告 |
| 保险被白嫖 | 毛利为负 | 依从率门槛；只顺延不退现；触发率过高先修课 |
| 自带 Key 劝退小白 | 转化差 | 体验档提供有限额托管；Pro 才推荐自带 |
| 公网版权投诉 | 用户上传盗版教材 | 条款写明用户保证授权；投诉即停该课 |
| 公开看板复活 | 行为扭曲回刷课 | 继续降权，团队也不做排行 |

## 9. 给设计与研发的一页摘要

**公网上卖的不是私教口吻，是一份别人无法刷出来的结果。**

因此下一阶段研发顺序是：

1. 把现有掌握门 + FSRS **包成答辩和 PDF**（能对外给）。  
2. 把负担提示 **升级成熔断**（能对用户狠）。  
3. 把 14 日保持率 **升级成保险规则**（能对续费负责）。  
4. 把分享 **升级成上岗闸**（能对公收款）。  

文案禁用：已完成、智能提升、元宇宙学习、全网首创 AI 老师。  
文案必用：已理解、尚未记住、已记住、合上资料、14 日保持、不在资料里。

对标策略不变：学 Khanmigo 的不代做、学 NotebookLM 的不离开资料、学 Anki 的按遗忘找你。对外多说一句：**我们把这三件事做成一门课里的一条路，并且敢用 14 日提取率对你负责。** 这就是可发布、可收费、可转介绍的产品。
