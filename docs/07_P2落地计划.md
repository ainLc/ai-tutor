# P2 落地计划

> 依据：`05` §10.9、`06` D7，以及「管道不是新游戏」的决策。  
> 原则：接到现有闭环上；能力进适配层；先 Web 后壳。  
> 原生 App 本阶段不做，用 PWA 验证通勤复习。

## 顺序与验收

| 步 | 能力 | 做法 | 验收 |
|---|---|---|---|
| 1 | OCR | 文本层字太少才识别；最多 15 页；识别结果当拆课原文 | 扫描 PDF 能拆课；文本 PDF 仍走 pypdf |
| 2 | 导图 | 用已有章/点生成只读 Mermaid 总览，不让模型另画一棵树 | 听课页能看到整门课结构，点目录仍进掌握门 |
| 3 | 语音 | 浏览器 TTS 朗读题面/补讲；Web Speech 口答写入文本框；评分仍是自评 | 复习页能听、能说；Again 后可听补讲 |
| 4 | PWA | 可安装 + 应用壳缓存 + 离线复习队列（评分联网补传） | 手机可「添加到主屏幕」；断网能翻上次缓存的卡 |

不做：播客课、可编辑脑图、模型听口误自动打 FSRS、Flutter/RN 重写。

## 落地记录（2026-09-10）

1. OCR：`backend/app/core/ocr.py`，文本层优先，不足则 RapidOCR，最多 15 页。  
2. 导图：听课页「结构总览」，`CourseMap.vue` 投影已有大纲。  
3. 语音：复习页朗读题面/答案/补讲 + 口答写入文本框。  
4. PWA：`manifest.webmanifest` + `sw.js` 缓存应用壳；复习队列 IndexedDB，评分离线补传。  
5. 原生 App：仍不做。
