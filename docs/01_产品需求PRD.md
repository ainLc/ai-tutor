# 产品需求文档（PRD）—— AI 私教学习系统

> **方向已更新（2026-09-08）。** 现行产品战略与需求以 [`05_学会并记住_产品战略与PRD.md`](./05_学会并记住_产品战略与PRD.md) 为准。本文档保留为 MVP 史记录：当时目标是「会讲、会画、会问」，尚未把「两周后还能提取」定义为产品成功。

## 1. 一句话定位

> 上传一套资料，得到一个「会讲课、会配图、会反问你、因材施教」的 AI 私教。

## 2. 目标用户与痛点

| 用户 | 痛点 |
|---|---|
| 自学技术的人 | 资料一堆，但没人讲、没重点、记不住、不知道自己懂没懂 |
| 培训/教学者 | 希望把资料快速变成可交互的课程，而不是做 PPT |

核心痛点一句话：**「看了很多，但没人考我、没图、没人确认我到底学会没」**。

## 3. 核心价值主张

真人好老师的三个特征，我们把它产品化：

1. **会讲课** → 把资料拆成课，逻辑清楚、通俗、好记
2. **会画图** → 每个难点自动配架构图/流程图，帮助理解
3. **会反问** → 讲完关键点主动提问，根据你的回答调整，检验你真懂了没

## 4. 核心闭环（MVP）

```
上传资料
  → 自动拆课（课程 → 章节 → 知识点）
  → AI 讲课（流式 + 配图）
  → 反问用户
  → 根据回答调整 / 进入下一知识点
  → 记录学习进度
```

## 5. 功能清单

### MVP（第一版必须）
- [x] 上传资料（支持 md / txt / pdf / zip）
- [x] 自动拆解课程结构
- [x] 流式讲课（边生成边显示，降低等待感）
- [x] 自动配图（Mermaid 架构图/流程图）
- [x] 讲解中反问用户（苏格拉底式）
- [x] 学习进度记录与断点续学

### 后续迭代（第二版+）
- [ ] 测验与评分（每课小测、自动判卷）
- [ ] 复习计划（间隔重复/记忆曲线）
- [ ] 学习报告（掌握度雷达图）
- [ ] 多资料库管理、多课程并行
- [ ] 语音讲解（TTS）
- [ ] 课后自动生成思维导图

## 6. 非目标（第一版不做）

- 不做移动端 App
- 不做多用户/账号体系（单机单用户）
- 不做视频/语音合成讲解
- 不做联网搜索能力

## 7. 成功标准

- 上传一份资料后，5 分钟内能得到可用的课程结构
- 每个知识点的讲解都带至少一张图
- 反问环节能准确识别用户「没懂」，并针对性补讲
- 学习进度不丢，关掉重开能续上

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 资料过长/格式乱 | 后端先做结构解析，失败降级为「全文分段」 |
| LLM 拆课不稳定 | 用结构化输出 + 校验 + 重试 |
| 配图质量参差 | 限定图类型（流程图/架构图/对比表），给 LLM 明确模板 |
| 反问识别用户懂不懂 | 反问后用结构化判断「已掌握/部分掌握/未掌握」 |
