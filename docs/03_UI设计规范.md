# UI 设计规范 —— AI 私教学习系统

> v2｜2026-09-11  
> 视觉要同时完成两件事：学习时像书房，对外交付时像一份别人刷不出来的纸。

## 1. 设计理念

**安静的私人书房，桌上有一份对得起别人的掌握凭证。**

关键词：**纸感、层级、诚实进度、仪式感克制。**  
不是科技蓝渐变，不是课程商城，不是排行榜。主色仍是靛蓝（智慧），底色改为暖纸，让长时间阅读不发冷。

文案禁用：已完成、智能提升、开始学习之旅、全网首创。  
文案必用：已理解、尚未记住、已记住、合上资料、14 日保持、不在资料里。

## 3. 字体与排版

- 正文：系统无衬线（PingFang SC / Microsoft YaHei / Segoe UI），15–16px，行高 1.7
- 展示标题（落地页、凭证、今日大数字）：衬线栈 `Songti SC / STSong / Palatino / Iowan Old Style`，字重 600
- 讲解正文宽度 **≤ 720px**
- 数字（到期张数、保持率）：字距略收紧，字重 700

## 4. 布局与页面职责

### 4.1 顶栏
Logo（书脊印）+ 今日 / 记忆练习 / 掌握 / 设置。  
主按钮文案：**上传将用于过关的那份资料**（短：上传资料）。

### 4.2 落地 / 登录
一句话：**合上你的资料，两周后还要能讲。**  
演示双进度，不写「智能 AI」。注册区附隐私与条款链接。

### 4.3 今日（有课）
三张主卡：到期复习（最大）、欠账、下一步。  
过载时复习卡变为熔断：锁新课，勾选知情后才能学新的。  
课程卡必须露出双进度；记忆轴未满时标签用琥珀色「已学过，尚未记住」。

### 4.4 听课
左目录、中讲解、结构总览可折叠。  
熔断锁只挡「未开始」；补讲与复习可进。  
过关卡用主色描边；对照原文、举报「不在资料里」始终可及。  
课过关后出现「合上书答辩」入口，而不是「已完成」徽章。

### 4.5 记忆练习
单栏 640px。题面大、答案收。评分四色块等宽。空状态引导去学新课，不说「打卡成功」。

### 4.6 掌握
14 日保持率是第一数字。公开看板保持折叠。每课可进入答辩 / 打开凭证。

### 4.7 合上书答辩
闭卷仪式：倒计时感的题序、无原文、无选项。通过后进入一页凭证，提供「打印 / 另存 PDF」。

### 4.8 凭证
A4 纸面：页眉「合上资料仍会」、指纹短码、双进度、题与答摘要。体验套餐斜向水印。打印时隐藏导航。

### 4.9 设置
上：套餐与配额。中：模型 Key。下：危险区删除账号。

## 5. 组件

- **双进度**：理解青绿、记忆靛蓝；「尚未记住」标签加粗、琥珀色
- **熔断条**：暖底、必须勾选才能解锁，禁止轻飘 toast
- **过关卡**：主色 2px 描边 + 浅靛底
- **课程卡**：纸面投影、首字印、双进度、分享/答辩/删除
- **空状态**：上传将用于过关的那份资料

## 6. 动效与可访问

- 动效 ≤ 200ms，只用于状态切换，不用作卖点
- 对比度 WCAG AA；焦点环使用主色 3px 外光
- 流式输出必须能停；熔断与删账号必须二次确认
